# INTENT-0003 · 틀리거나 불필요한 표시 제거, 한반도 지도, UI/UX 정리

- 상태: 완료
- 작성 2026-10-26 / 갱신 2026-10-26

## 왜

사용자 요청: "상세나 데이터 중에 틀리거나 하드코딩으로 들어가거나 굳이? 싶은 것들은 안 보이도록 제거하세요. 댐 위치를 한반도 그림 기준으로 점으로 표기하는 등 시각적으로 보여 주면 좋겠다. 기본 화면에서는 지도 기준으로 저수율이 색칠로 보이면 더 좋겠다. UI/UX 전반을 점검해 쓸데없는 것은 치우고 깔끔하고 직관적으로."

점검해 보니 화면에는 포털 자료처럼 보이지만 사이트가 지어낸 것들이 섞여 있었다.

- 상태 배지 "가뭄경계·주의·관심"은 저수율 40·50·60% 고정 기준이었다. 공식 가뭄 단계는 댐마다 기준이 다르다.
- "방류 중"은 총방류량 20㎥/s 이상이면 붙었다. 평상시 발전 방류도 여기에 걸렸고, 이 배지가 우선 표시돼 저수율이 낮은 댐의 상태가 가려졌다.
- "홍수주의"도 사이트가 정한 수위 비율 기준이었다.
- 티커는 주암댐 문구를 하드코딩하고 있었다. JSON-LD에는 연도(2022~2026)와 쓰지 않는 출처(WAMIS)가 박혀 있었고, 위치 프리셋에는 사실과 다른 "IP 오차 보정" 문구가 붙어 있었다.
- 서로 무관한 댐들의 유입·방류량 합계, 모든 댐이 같은 "관리기관 K-water" 표기, 무한 반짝임 같은 장식 애니메이션도 정보가 없었다.

## 무엇

- 화면의 모든 숫자와 비교는 포털 관측값이거나 그 산술이다. 사이트가 판정 라벨을 지어 붙이지 않는다.
- 기본 화면 첫 영역은 한반도 지도다. 36개 댐을 실제 위치에 점으로 찍고, 색은 저수율 구간, 크기는 총저수용량으로 나타낸다. 점을 누르면 상세가 열리고, 필터에서 빠진 댐은 흐려진다.
- 요약 영역은 사실 기반 카드 4개(전국 평균과 예년 대비, 총 저수량, 예년보다 낮은 댐 수, 최저 저수율 댐)와 수계별 저수율로 구성된다. 수계 행을 누르면 그 수계로 필터된다.
- 상세 모달에는 그 댐의 위치를 보여 주는 미니맵이 있다.

## 수용 기준

- [x] 상태 배지·상태 열·상태 필터·고정 기준(THRESHOLDS)이 코드와 화면에서 사라진다. 표는 9열이다.
- [x] 티커, 도시 프리셋, 유입·방류 합계 카드, 관리기관 표기, 장식 애니메이션, JSON-LD 하드코딩 연도와 미사용 출처가 사라진다.
- [x] 지도: 36개 점이 모두 지도 틀 안의 실제 위치에 찍히고(남북·동서 순서 보존), 울릉도·독도는 인셋에 그려진다. 점 클릭과 Enter로 상세가 열리고, 필터에서 빠진 댐은 흐려진다.
- [x] 요약 카드와 수계 요약 값이 포털 관측값에서 계산되고, 수계 행을 누르면 필터가 걸리고 다시 누르면 풀린다. 최저 카드를 누르면 그 댐 상세가 열린다.
- [x] 22개 언어에서 새 문구에 플레이스홀더나 키 이름 노출이 없고 한국어가 섞이지 않는다(의도한 이중 언어 라벨 제외).
- [x] 360~1440px에서 페이지 가로 넘침이 없고, 한국어·영어는 1024px 이상에서 표 9열이 가로 스크롤 없이 들어간다.
- [x] 기존 기능(정렬·필터·검색·모달·기간 추이·키보드·포커스·새 관측 반영·위치 영속·CSV·테마·저장소 차단 환경)이 그대로 동작한다.

## 제약

- 프로젝트 인텐트의 제약을 따른다. 런타임 의존성 없이 정적 사이트를 유지한다. 지도 외곽선은 공개 도메인 데이터(Natural Earth)를 단순화해 코드에 넣는다.

## 비범위

- 댐 이름의 다국어 표기(고유명사라 한국어 유지).
- 시군구 경계나 수계 유역 경계 지도.

## 열린 질문 → 결정

- 결정(사용자 지시): 틀리거나 하드코딩된 표시는 제거한다. 상태 배지 제거는 프로젝트 인텐트 영구 결정(2026-10-26)으로 올렸다.

### 구조 지도 변경

`js/map.js`(한반도 외곽선, 투영, 점 SVG)를 추가했다. `js/data.js`는 `THRESHOLDS`/상태 판정을 버리고 `RATE_BANDS`, `rateBand()`, `getBasinMetrics()`를 얻었다. `js/i18n.js`는 `data-i18n*` 속성으로 정적 문구를 일괄 적용한다. `docs/ARCHITECTURE.md`를 참조한다.

### 남는 위험

- 독일어·러시아어 등 단어가 긴 언어는 1024px 폭에서 표가 가로로 스크롤된다(1280px 이상은 문제없음).
- 예년 대비는 포털이 주는 예년값에 의존한다. 예년값이 없는 댐은 "예년보다 낮은 댐" 집계와 필터에서 빠진다.

### 발견한 부채

- 이전 버전에서 도시 프리셋으로 저장된 위치는 계속 복원된다(`source: 'preset'`). 지금 화면에는 프리셋을 다시 고르는 UI가 없어, 해제(기본순 복귀) 후에는 GPS만 쓸 수 있다.
